# VitaMenu
Bo2 mod menu meant for fun, speedruns, and debugging


--------------------------
# Versions:

Due to the limits of bo2 and it's scripts, I've made three different versions of the menu, with 2 of the version off loading a lot of features. The full version doesn't hurt bo2's performance, but there are a lot "max limits" that come with bo2's script due to them needing to work on the xbox 360/ps3 , so the smaller versions of the menu free up space for other mods if you have any installed. 

**- Vita Menu:** The full menu complete with every feature
**- Vita Menu Lite:** All features minus the cheats menu
**- Vita Menu Fun:** Only has the fun menu

--------------------------
# Features:

## Quick Options:
- Fast Restart
- Toggle Fog
- Delete Death Barriers
- Zombies Left In Round Counter

## Debugging:
- Print mob of the dead key location.

*the key's location is dead ass just 1 or 2 in the source code, so thats what is shown*

- Build All Tranzit Bus Parts
